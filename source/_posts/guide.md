欢迎使用 **Yz630's Blog**。平时写 WP，只需要打开写作台、输入文字、粘贴截图，再保存文章。这篇说明可以随时从顶部导航的“使用说明”打开。

<!-- more -->

## 1. 打开和关闭

在电脑的博客项目文件夹 `my-wp-blog` 中，双击 **打开写作台.cmd**，浏览器会打开编辑界面；博客预览也会在后台一起启动。

| 入口 | 用途 |
| --- | --- |
| 打开写作台.cmd | 写文章、放图片、管理草稿 |
| 打开博客.cmd | 查看完整博客效果 |
| 停止服务.cmd | 写完以后关闭后台服务 |

服务启动后，也可以直接访问 [本机写作台](http://127.0.0.1:4001/) 和 [本机博客](http://127.0.0.1:4000/)。这些地址只指向你正在使用的这台电脑。

关闭浏览器不会关闭后台服务。电脑重启后，再双击启动文件即可，不需要每次输入命令。

## 2. 新建一篇 WP

下图是写作台的分栏界面：左侧选择文章，中间编辑正文，右侧查看预览。

![写作台的文章列表、Markdown 编辑区与正文预览](/images/2026-10/1792589895426-277c5b9154.jpg)

1. 打开写作台，点击左侧 **新建 WP**。
2. 输入文章标题，例如 `比赛名 - 题目名 - Misc`。
3. 填写分类、标签和摘要。分类可以写 `CTF, Misc`，表示 CTF 下的 Misc；标签如 `Python, 隐写`，用逗号隔开。
4. 在正文编辑区写内容。新文章会带有题目信息、思路、过程、脚本和复盘几个小节，可以按需要删改。
5. 还没写完时选择 **草稿**，完成后可以改成 **文章**，再点击 **保存文章**。

左侧文章列表可以再次打开已保存的文章，也可以输入标题或标签进行筛选。

## 3. 插入截图和图片

最方便的方式是直接粘贴截图：

1. 按 `Win + Shift + S`，截取需要的画面。
2. 回到写作台，点击正文中要插图的位置。
3. 按 `Ctrl + V`，图片会自动保存，正文里会出现图片引用。
4. 点击 **保存文章**，把新增的引用一起保存。

也可以把图片文件拖到正文编辑区，或者点击工具栏的 **插入图片** 选择文件，支持一次选择多张。

支持 PNG、JPG、WebP、GIF，每张不超过 **15 MB**。图片保存在项目的 `source/images/` 文件夹中，新图片文件名带有日期，无需图床账号。博客里的图片可以点击放大。

> 图片文件保存完成后，仍需保存文章。移动或删除图片文件会导致正文里的图片无法显示。

## 4. 常用排版

正文使用 Markdown。工具栏提供标题、加粗、代码块、引用和插图按钮，也可以直接输入下面这些写法：

| 想要的效果 | 输入方法 |
| --- | --- |
| 小节标题 | `## 解题过程` |
| 加粗 | `**重点内容**` |
| 列表 | 每行开头输入 `- ` |
| 行内命令 | 用一对反引号包住命令 |
| 引用 | 每行开头输入 `> ` |
| 链接 | `[显示文字](网址)` |

粘贴脚本时，点击工具栏的 **代码块** 按钮，在生成的两行反引号之间放入代码，把 `python` 改成对应语言即可。保留代码缩进，正文编辑区按 `Tab` 会插入四个空格。

工具栏右侧可以切换 **分栏 / 编辑 / 预览**。分栏适合一边写一边查看；窗口较窄时，可以单独切到预览。这里预览的是正文，最终主题效果请到博客里查看。

## 5. 保存、草稿与查看文章

点击右上角 **保存文章**，或按 `Ctrl + S`。看到 **已保存到本地**，才表示内容已经写入电脑里的 Markdown 文件。

| 状态 | 保存后在哪里看到 |
| --- | --- |
| 草稿 · 仅写作台可见 | 写作台的文章列表，不出现在博客里 |
| 文章 · 本地博客可见 | 写作台和本地博客，右上角可点“查看文章” |

修改已保存的文章后，本地博客会重新生成内容。点击 **查看文章** 或刷新已打开的文章页即可检查效果。

**目前网站在本机运行，保存不等于发布到互联网。** 以后配置公开网址与部署后，访客才能访问。届时只发布生成好的博客页面，写作台留在自己的电脑上。

## 6. 修改名称和外观

写作台左下角的 **站点设置** 可以修改博客名称、作者昵称和简介。保存后预览服务会重新加载配置，稍等几秒刷新博客即可。

当前使用灯塔日落背景。确定新图片后，可以替换项目中的 `source/assets/lighthouse-dusk.png`；头像文件是 `source/assets/avatar.svg`。如果新图片的格式或文件名不同，需要同时调整主题配置中的路径。

Wallpaper Engine 联动暂时保留为后续想法，当前没有启用。

## 7. 文件存在哪里，如何备份

| 项目内的位置 | 内容 |
| --- | --- |
| `source/_posts/` | 博客文章，每篇一个 `.md` 文件 |
| `source/_drafts/` | 草稿 |
| `source/images/` | 写作时插入的图片 |
| `.local/history/` | 写作台覆盖保存前保留的历史版本 |
| `_config.yml` | 网站名称、作者等基础设置 |
| `_config.butterfly.yml` | 主题设置 |

建议定期备份整个 `my-wp-blog` 文件夹。`node_modules/` 和 `public/` 可以重新生成，但正文、图片、配置和自定义文件需要保留。

浏览器会临时保留未保存内容，以帮助意外关闭后的恢复；它不能替代点击保存和文件备份。历史版本在同一台电脑上，也不能替代外部备份。

## 8. 遇到问题时

- **网页打不开**：先双击“打开写作台.cmd”，等待服务启动。
- **提示端口占用**：先双击“停止服务.cmd”；如果另一个终端还在运行旧的 Hexo 服务，在那个终端按 `Ctrl + C`，然后再启动。
- **图片不显示**：确认插图后保存了文章、图片文件没有被移动，再刷新页面。
- **提示文章已被其他窗口修改**：先复制当前正文到安全的位置，再重新打开文章，合并内容后保存，避免覆盖另一个版本。
- **想恢复旧内容**：在 `.local/history/` 中找到对应文章的备份，先复制出来查看，再恢复需要的部分。

项目根目录还有一份 **使用说明.md**，即使网站没有启动，也可以用文本编辑器打开阅读。
